A mesma lista do dashboard, em JSON.

GET /api/recommendations

Pública, sem autenticação, sem limite de taxa específico (mas nada educado abusa). Só leitura -- essa rota nunca fala com a Steam, é o mesmo cache que alimenta o dashboard.

Exemplo

{{ exemplo_url }}

{
  "ultimo_scan": {
    "categoria": "Todas as categorias",
    "ts": 1792884599.44
  },
  "candidatos": [
    {
      "name": "AK-47 | Redline (Field-Tested)",
      "name_fmt": "AK-47 | Redline (Testada em Campo)",
      "price": 50.0,
      "price_fmt": "R$ 50,00",
      "score": 72,
      "case_label": "",
      "pump_risk": {"level": "low"},
      "reasons": ["Preço 10% abaixo do típico (+12)"],
      "market_url": "https://steamcommunity.com/market/listings/730/...",
      "icon_url": "https://community.cloudflare.steamstatic.com/economy/image/..."
    }
  ]
}

Campos

  • score — nota de 0 a 100 (ver dashboard pra entender o cálculo)
  • reasons — até 3 motivos factuais que mais somaram pontos
  • pump_risk.level — "low", "medium" ou "high"
  • icon_url — pode vir ausente, se o item nunca foi re-escaneado desde que isso foi adicionado

Limitado aos 20 melhores candidatos no momento. Pra filtros/ paginação completos, use as mesmas query strings do dashboard (?categoria=, ?nota_min=, ?preco_max=, ?q=) direto na página HTML -- a API JSON ainda não aceita esses parâmetros.
